whenever you create a new project.
follows these steps 
1. create project folder
2. install virtual env    -  pip install virtualenv
3. create virtual env     -  python -m venv env
4. activate virtual env   -  env\Scripts\Avtivate 
5. install flask - pip install flask 
6. create app.py file inside project folder.
7. write your app logic into your app.py file.
8. app run :- python filename.py  (Like - python app.py)
