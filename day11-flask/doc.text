how to make first app using flask.

1. install python   (done)
2. check python version (python --version)
3. make project folder (myflaskApp)
4. install virtual env (pip install virtualenv) 
5. create virtual env (create inside project folder - python -m venv venv)
6. activate virual env (env\Scripts\Activate)
7. install flask (pip install flask)
8. create an app.py file


    from flask import Flask
    app = Flask(__name__)
    @app.route("/")
    def home():
        return "Home Page!"

    if __name__ == "__main__":
        app.run()

9. run flask app  : - python app.py
10. open browser :-  http://127.0.0.1:5000   or localhost:5000
